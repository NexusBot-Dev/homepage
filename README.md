# Nexus Website

Website for [Nexus](https://trynexus.de), the focused Discord bot for streamers and gaming communities: features, Premium, changelog, wiki and legal pages.

## Features

- German and English with a language switcher
- Content from [Directus](https://directus.io): wiki, changelog, FAQ, imprint, privacy policy and terms of service
- Search across the wiki and pages (`Ctrl+K`)
- Strict Content Security Policy for scripts (hashes generated by Astro, no inline scripts)
- Privacy-friendly analytics with Matomo (no cookies, respects Do Not Track)
- SEO: localized meta tags, structured data, sitemap and robots.txt

## Tech stack

- [Astro 7](https://astro.build) with server-side rendering (`@astrojs/node`, standalone)
- Tailwind CSS 4
- Directus SDK
- Playwright for end-to-end tests

## Configuration

| Variable | Purpose |
|---|---|
| `DIRECTUS_URL` | Directus instance for wiki, changelog, FAQ and legal pages |
| `HOST`, `PORT` | Address the server listens on |

If Directus is unreachable, the pages fall back to built-in content where available.

Site-wide constants (invite link, Premium store link, support server) live in `src/config.ts`. All texts are in `src/i18n/`.

## Development

Requires Node.js 22.12 or newer (production runs Node.js 24).

```bash
npm ci
npm run dev        # development server
npm run build      # production build
node dist/server/entry.mjs
npx astro check    # type check
```

## Tests

```bash
npm run test:e2e         # all tests against the dev server
npm run test:e2e:build   # all tests against the production build, including the CSP tests
```

Astro only applies the Content Security Policy in production builds, so the CSP tests run with `test:e2e:build` only.
